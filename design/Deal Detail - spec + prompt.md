# หน้ารายละเอียดดีล (Deal Detail) — ส่วนที่เพิ่มใหม่

ไฟล์นี้คือ **เฉพาะหน้ารายละเอียดดีล** ที่คลิกเข้าจากตาราง/บอร์ดในหน้า "ดีล (Pipeline)"
ใช้เป็นสเปกภาพ + reference โครงสร้างให้ Claude Code

---

## Design tokens (เหมือนทั้งระบบ)
- Font: 'IBM Plex Sans Thai' + 'IBM Plex Sans', weight 400/500/600/700
- Primary #2563EB · แดง #E4342E · เขียว #178A55/#EBF7F0 · เหลือง #B7791F/#FBF3E2
- BG #EEF1F5 · card #fff · border #E4E8EE · ช่อง input #F6F8FB
- radius card 16–18px, ปุ่ม/ช่อง 10–12px
- เงิน: ห้าม ฿ · หน้านี้ไม่ใช่ Dashboard → ห้ามใช้ MB · มูลค่า 0/null → "—"

---

## โครงสร้างหน้า (บนลงล่าง)

1. **ลิงก์ย้อนกลับ** `← <ชื่อดีล>`
2. **Header** — ชื่อดีล + แท็ก BU + แท็กคุณภาพ ("ไม่ใช่ lead คุณภาพ" สีเหลือง) + บรรทัด "ดีล · มูลค่า —"
   ปุ่มขวา: `บันทึกการติดต่อ` (primary) · `สร้างงานให้ทีม` (secondary) · ปุ่มลบ (icon แดง)
3. **Stage stepper** — การ์ดหัวข้อ "สถานะการขาย — คลิกเพื่อเลื่อนสถานะดีล" มุมขวา "ขั้นปัจจุบัน: ลีด"
   แถว pill: ลีด(active น้ำเงิน) — มีศักยภาพ — คาดหวัง — กำลังเจรจา … ชิดขวา: `✓ ได้งาน` (เขียว outline) · `✕ ปิด/แพ้` (แดง outline) · คลิก pill = เลื่อน stage (เรียก API เดิม)
4. **การ์ดสถิติ 4 ช่อง** — เปิดดีลมาแล้ว / ติดต่อล่าสุด / งานของดีลนี้ / ความน่าจะปิดได้
5. **แถบเตือนเหลือง** — "ยังไม่มีงาน/นัดติดตามถัดไป" + ปุ่ม `บันทึกการติดต่อ + ตั้งนัด` (แสดงเมื่อไม่มี task ค้าง)
6. **2 คอลัมน์**: `งานของดีลนี้ (n ค้าง)` + ปุ่มมอบหมาย (empty state) | การ์ด `✨ AI วิเคราะห์ Lead` (ช่องเลขผู้เสียภาษี + ปุ่มวิเคราะห์)
7. **2 คอลัมน์**: `ประวัติการติดต่อ & งาน` (timeline) | side card `ลูกค้า & ผู้ติดต่อ` (ผู้ติดต่อ/โทร/อีเมล/Sale/ที่มา lead/Pain points)
8. **สินค้า/บริการในดีลนี้** — แถวรายการ (บริการ dropdown / จำนวน / ราคาต่อหน่วย / รอบบิล / ลบ) + ฟิลด์ย่อยตามบริการ + ปุ่มบันทึก
9. **ฟอร์มแก้ไขดีล & ข้อมูลลูกค้า** — พับได้ (accordion) grid 2 คอลัมน์ (ชื่อดีล/มูลค่า/ความน่าจะปิด%/คาดว่าจะปิด/ที่มา/Keyword/Pain points/เหตุผลไม่ใช่ lead คุณภาพ)

---

## Prompt สำหรับ Claude Code (เฉพาะหน้านี้)

```markdown
# เพิ่ม/ปรับหน้า "รายละเอียดดีล" (Deal Detail) ตามสเปกที่แนบ

อ่านไฟล์ `design/Deal Detail — spec + prompt.md` เป็นสเปกภาพหลักของหน้ารายละเอียดดีล
(เข้าจากการคลิกแถวในตาราง/การ์ดในบอร์ด Kanban หน้า Pipeline)

## กติกา
- ห้ามแก้ business logic / API / schema — ทำเฉพาะชั้น presentation (JSX + Tailwind/CSS)
- คงภาษาไทย i18n เดิม · responsive ไม่พังที่ 900–1100px
- เงิน: ห้ามใช้ ฿ · หน้านี้ห้ามใช้ MB · ค่า 0/null → "—"

## ต้องทำ
1. เรียง layout ตาม 9 section ในสเปก (บนลงล่าง)
2. **Header อยู่บนสุดเสมอ** ไม่ถูก scroll ตัด (bug เดิมของหน้า detail)
3. **Stage stepper**: pill คลิกได้ = เลื่อน stage ผ่าน mutation เดิม, ขั้นปัจจุบัน highlight น้ำเงิน,
   ได้งาน/ปิดแพ้ เป็นปุ่มแยกชิดขวา (เขียว/แดง outline)
4. **แถบเตือนเหลือง** แสดงเมื่อ task ค้าง = 0 เท่านั้น
5. **ฟอร์มแก้ไข** เป็น accordion พับได้ (default พับ), chevron หมุนตามสถานะเปิด/ปิด
6. ปุ่ม icon-only (ลบ/รีเฟรช/ปฏิทิน) ต้องมี aria-label
7. ใช้ Button component เดียวกับทั้งระบบ (primary/secondary/ghost/danger)

## Design tokens
ดูหัวข้อ Design tokens ในไฟล์สเปก — ใช้ให้ตรง (สี/ฟอนต์/radius/ช่อง input #F6F8FB)
```
